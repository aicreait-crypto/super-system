# Домен и хостинг — что делать

Проверено 1 сентября 2026. Цены — на момент проверки, могут измениться.

---

## Публикация — самый быстрый путь (2 минуты)

1. Распакуй **оба** архива в одну папку. Внутри должны лежать `index.html`, `lavori.html`,
   `brief.html`, `privacy.html`, `styles.css`, `script.js`, папки `immagini/` и `video/`.
2. Открой **https://vercel.com/drop** (ты уже авторизована).
3. Перетащи туда **папку целиком** — не архив, именно папку.
4. Vercel сам определит, что это статический сайт, и через полминуты выдаст ссылку вида
   `aicreait-xxxx.vercel.app`. Она сразу рабочая и её можно кому угодно отправлять.

Файлы `admin.html`, `*.md` и папку `drive2` в публикацию класть не нужно — они для работы,
не для посетителей. В архиве `aicreait-1-sito.zip` они есть; если хочешь чистую публикацию,
удали их из папки перед тем, как перетаскивать.

## Почему я не выложила сама

Инструмент Vercel, который у меня есть, принимает файлы только текстом внутри самого запроса.
Сайт весит 48 МБ — столько текста в один запрос физически не помещается.

Через GitHub тоже не вышло, по двум независимым причинам:
- доступ к репозиториям у этой сессии выдаётся заранее и на конкретные адреса;
  `aicreait-crypto/super-system` в этот список не входит, и добавить его я не могу;
- сеть контейнера пропускает только `api.github.com`, а `git push` идёт на `github.com` —
  он заблокирован на уровне прокси.

Так что публикация — за тобой, зато это буквально одно перетаскивание.

## Автообновление на будущее

Если захочешь, чтобы сайт обновлялся сам:

1. В Vercel → **Add New… → Project → Import Git Repository** → выбери `super-system`.
2. Framework Preset: **Other**. Root Directory: оставь пустым. Build Command: пустой.
   Output Directory: пустой.
3. Дальше заливаешь файлы в репозиторий любым способом (хоть через веб-интерфейс GitHub,
   кнопка **Add file → Upload files**) — Vercel пересоберёт сайт сам при каждом коммите.

## Домен

Пока адрес будет `*.vercel.app` — это нормально для старта.
Когда решишь взять свой: в Vercel → Project → Settings → Domains → Add.
`aicreait.com` стоит около $11–15 в год, `aicrea.it` — итальянская зона, дороже и требует
подтверждения резидентства.
